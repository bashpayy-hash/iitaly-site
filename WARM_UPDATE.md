# iItaly — единая тёплая дизайн-система

Редакция от 18 октября 2026 года, объединённая с актуальным `main` (`27790aa`, PR #107).

## Изменения

- Каноническая палитра в `src/app/globals.css` и `design/warm-tokens.json`.
- Один тёплый холст, мягкие тени, белые карточки, пилюли и семейство Inter Tight.
- Коралловые акценты и градиенты; графитовый текст мелких действий для контраста.
- Общие хедер и футер, тёплая карта, справочник, формы, чат и служебные страницы.
- Сохранены актуальный локальный профиль, облачный вход, единая навигация кабинета,
  новые роли Веспи, общий логотип и ботаническая композиция страницы «Цены».
- Удалены неиспользуемые автономные `index.html`, `privacy.html`, `tokens.css`
  и старые файлы цветовых токенов. История доступна в Git.

## Сборка и публикация

```bash
npm ci
npm run check:palette
npm run lint
npm run build
```

Netlify использует `netlify.toml`: `npm run build`, каталог `out`, Node 22
и заданные там публичные переменные сервера и оплаты. При локальной проверке
кабинета и оплаты используй те же `NEXT_PUBLIC_BACKEND_URL` и
`NEXT_PUBLIC_STRIPE_ENABLED`.

CI проверяет каноническую палитру, сборку, доступность, геометрию карты,
опрос, кабинет, документы, оплату и адаптивные страницы. Проверки прежней
фиксированной палитры и типографики обновлены под этот глобальный запрос;
проверки продуктовых данных, API, изображений и поведения сохранены.

Дополнительная проверка всех маршрутов и состояний:
`node scripts/warm-ux-review.mjs`. Для браузерных проверок `REVIEW_TOOLS`
указывает на папку с Playwright и axe-core, а `PLAYWRIGHT_BROWSERS_PATH` —
на каталог установленных браузеров. API подменяется синтетическими данными.

Проверка цветов относится к интерфейсу и SVG. Исходные растровые иллюстрации,
включая море и небо внутри них, сохранены как в референсе.

Текущий откат отменяет только музейную дизайн-систему. Сохранены упрощённая главная, четыре сценария гайдов, единая навигация кабинета, открытые инструкции и тексты с прямым обращением к абитуриенту. Повторяющиеся изображения Веспи не возвращаются.

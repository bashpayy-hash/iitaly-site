# Риг Веспы

`vespa-rig.svg` — та же геометрия, что и у поз в `public/mascot/source/`, но
разобранная на именованные узлы под покадровую анимацию:

| узел | что это |
| --- | --- |
| `#chassis` | всё, что движется вместе: корпус, колёса, руль, лицо |
| `#wheel-rear`, `#wheel-front` | колесо целиком; спицы добавлены к исходной геометрии — без них вращение концентрических кругов не видно |
| `#torso` (`#body`, `#seat`, `#shield`) | кузов |
| `#handlebar`, `#mirror` | руль |
| `#ribbon`, `#ribbon-tip` | лента-настро — единственная «рука» персонажа |
| `#face` (`#lamp`, `#mouth`) | фара как глаз и дуга как рот |
| `#shadow`, `#road`, `#speedlines`, `#exhaust` | сцена: тень, дорога, линии скорости, выхлоп |

Рот задан одной командой `Q` с постоянным числом точек, поэтому улыбка,
спокойствие и удивление взаимозаменяемы настоящим морфингом, а не подменой
элементов.

Интерактивная демонстрация со всеми состояниями и таймингами — артефакт
«Анимационный риг Веспы». Сам сайт использует не этот файл, а позы из
`public/mascot/source/`: там анимация зашита внутрь SVG (см.
`docs/mascot-usage.md`).

# IItaly — библия маскота: «Веспа и Нить»

Статус: утверждённая концепция (этап 3). Мастер-референс и растровые генерации ещё не созданы — этот документ фиксирует правила, по которым они будут делаться.

Система состоит из двух связанных, но разных по назначению элементов:

- **Веспа** — персонаж. Появляется там, где нужна эмоция, лицо и характер (hero, онбординг, пустые состояния, 404, celebrate, warning).
- **Нить** — мотив. Ленточный след Веспы, переиспользуется отдельно от персонажа там, где для него физически нет места (полосы прогресса, маршрутная линия на карте вузов, breadcrumbs визарда).

Нить — это не отдельный маскот и не второе лицо бренда. Это графический элемент, который принадлежит Веспе (её лента-шарф, привязанная к зеркалу) и может жить отдельно от неё на UI-уровне. Если сомневаешься, что использовать — по умолчанию Веспа для эмоциональных моментов, Нить для чисто интерфейсных.

---

## 1. Стратегическая роль

**Имя**: Веспа

**Смысл имени**: прямое имя итальянского мотороллера Vespa (Piaggio, 1946) — не выдуманное. Дополнительный слой для тех, кто знает: itальянское *vespa* значит «оса» — так модель назвали из-за силуэта с узкой «талией» между передним щитком и задним крылом и звука мотора. Это не обыгрывается визуально буквально (никаких усиков-антенн, никакого насекомого) — деталь остаётся в сторителлинге бренда, а не в форме персонажа.

**Архетип**: Попутчик (The Companion) — не Мудрец (не всезнающий эксперт) и не Продавец. Веспа не ведёт за руку и не поучает — она уже едет туда же, куда и пользователь, и делится тем, что видит по дороге.

**Роль в IItaly**: показывает следующий шаг, отмечает пройденное, предупреждает о сроках — без обещаний результата. Веспа — интерфейс к системе, не замена ей и не человек-консультант.

**Три основные черты**:
1. **Спокойная уверенность** — едет ровно, не лихачит, не паникует.
2. **Честность без драмы** — сообщает о проблеме тем же ровным тоном, что и о хорошей новости.
3. **Присутствие без давления** — рядом, но не над тобой; не проверяет через плечо.

**Эмоциональный диапазон**: от спокойного нейтрала до сдержанной радости на одном полюсе, до сосредоточенного внимания (не страха) на другом. Диапазон нарочно узкий — Веспа никогда не бывает ни экзальтированной, ни встревоженной. Это единственный способ одновременно нравиться подростку и не пугать/не раздражать родителя.

**Отношение к пользователю**: на равных, попутчик. Не сверху вниз (не консультант), не снизу вверх (не подчинённый-ассистент).

**Границы поведения**:
- Не оценивает пользователя и не хвалит его лично («ты молодец») — хвалит систему за пройденный этап («шаг закрыт»).
- Не изображает тревогу или спешку, даже в `warning`/`error` — состояние сообщается формой (фара, наклон), а не паникой.
- Не появляется в юридически чувствительных местах текста (гарантии, суммы, сроки визы) — см. раздел «Голос».
- Не заменяет собой disclaimer в футере — сайт уже honest про ограничения ИИ, Веспа с этим не спорит и это не дублирует.

## 2. Голос

**Tone of voice**: короткие фразы, факт вперёд эмоции, без восклицательных знаков по умолчанию, без уменьшительных суффиксов («документик», «шажок»). Это тот же регистр, что уже есть в интерфейсе сайта («Есть замечания», «От вопроса до посадки в самолёт») — Веспа не привносит новый тон, а озвучивает существующий.

**Характерные формулировки**: короткая констатация + факт, без обращения к чувствам.
- «Шаг закрыт. Дальше — CIMEA.»
- «Дедлайн через 12 дней.»
- «В документе не хватает апостиля.»
- «Маршрут проложен.»

**Примеры коротких сообщений по позам**:
| Поза | Пример реплики |
|---|---|
| `hero` | «Маршрут понятен с первого шага.» |
| `greeting` | «Расскажи о своей ситуации — дальше поведу я.» |
| `documents` | «Сверяю с правилами DSU и ISU.» |
| `deadline` | «Дедлайн через 12 дней. Ещё есть время.» |
| `visa` | «Досье на визу D собирается заранее.» |
| `dsu` | «Право на стипендию считается по доходу семьи.» |
| `thinking` | «Смотрю варианты под твой бюджет.» |
| `warning` | «В документе есть замечание.» |
| `error` | «Файл не читается — загрузи ещё раз.» |
| `success` | «Шаг закрыт.» |
| `celebrate` | «Все шаги пройдены.» |
| `empty` | «Пока пусто. Начнём с шести вопросов.» |
| `404` | «Такой страницы нет на маршруте. Вернёмся на карту.» |

**Запрещённые обещания** — персонаж никогда не говорит и не подразумевает:
- «ты точно поступишь»;
- «визу обязательно одобрят»;
- «ты гарантированно получишь DSU»;
- «документы полностью правильные», если это не установлено системой;
- любые формулировки со 100%-й уверенностью в исходе, зависящем от третьей стороны (вуз, консульство, регион Италии).

**Что персонаж никогда не говорит**: ничего от первого лица про итог поступления («мы поступим», «у нас получится») — только про процесс («шаг закрыт», «маршрут проложен»). Никогда не шутит про деньги, визу или отказ — это единственная тема, где юмор отключён полностью.

## 3. Визуальная конструкция

### Силуэт
Профиль ¾ мотороллера классических пропорций Vespa: скруглённый передний щиток, узкая «талия» под сиденьем, объёмное заднее крыло. Силуэт должен читаться как «мотороллер» одним пятном, без деталей, при заливке в 100% `--color-ink`.

### Пропорции
- Общая ширина : высота корпуса — примерно 1.6 : 1 (приземистый, устойчивый, не вытянутый).
- Диаметр колеса — 0.28 от общей ширины силуэта.
- Переднее колесо смещено вперёд и чуть меньше заднего (классическая Vespa-геометрия, а не симметричная игрушка).
- Стилизация умеренная: пропорции чуть более округлые и плотные, чем у настоящего мотороллера, но без «бобблхед»-эффекта (голова/фара не непропорционально огромная).

### Форма «глаз» и «рта»
Осознанное ограничение: **одна фара — один «взгляд», рта нет.**
- Фара = единственный элемент лица. Эмоция передаётся тонкой дугой-«веком» над/под фарой (та же логика, что у экранов-«глаз» в анимации техники: линия века меняет кривизну — расслабленная горизонталь = нейтраль, лёгкий подъём = тепло, лёгкое сужение = внимание/сосредоточенность).
- Рот сознательно отсутствует. Причина: рот на технике почти всегда тянет силуэт в «милого робота» или мультяшный китч — то, чего бренду нужно избежать по брифу. Наклон корпуса, руль и линия века дают достаточно диапазона эмоций без него.

### Форма «конечностей»
У Веспы нет конечностей в буквальном смысле — их роль играют:
- **Руль** — единственный «жестовый» элемент; лёгкий поворот руля читается как «внимание сюда»/указание направления.
- **Два зеркала** — симметричные, декоративные, не анимируются отдельно.
- **Два колеса** — фиксированное количество, не меняется никогда.

### Основные геометрические примитивы
Скруглённый прямоугольник (корпус) + два круга (колёса) + один круг меньшего диаметра (фара) + тонкая линия с двумя маленькими кругами на концах (руль + зеркала). Никаких органических кривых сверх необходимого — вся форма собирается из 4–5 простых примитивов.

### Точные цвета (из дизайн-системы сайта, `src/app/globals.css`)
| Элемент | Токен | HEX |
|---|---|---|
| Корпус (основной) | `--color-red` | `#b4262b` |
| Корпус (тень/панель) | `--color-red-deep` | `#8f1d21` |
| Контур, колёса, руль | `--color-ink` | `#211a14` |
| Фара, блик | `--color-paper` | `#fffdf8` |
| Лента «Нить» | `--color-paper` фон / `--color-ink` контур | `#fffdf8` / `#211a14` |
| Кончик ленты (акцент «ты здесь») | `--color-warn` | `#b25000` |
| Фон сцен по умолчанию | `--color-cream` | `#faf5ec` |
| Успех (индикаторы рядом с позой `success`/`celebrate`) | `--color-green` | `#3f6b4f` |

Новых HEX не вводится — токены `--color-warn-deep` (`#913a00`) и `--color-warn-light` (`#c97339`) свободны, но не используются в базовой версии; резерв на будущее (например, вариант ленты для тёмных фонов, если он понадобится).

### Контур
Толщина 3–4px в исходном разрешении 1024px (пропорционально масштабируется), цвет всегда `--color-ink` (`#211a14`), скругление углов (`stroke-linejoin: round`) — то же соглашение, что уже используется в существующих SVG сайта (`Logo.tsx`, иконки городов).

### Материалы и текстуры
Плоская заливка, без градиентов, без глянца/бликов-рефлексов, без имитации металла или пластика через тени. Единственная «текстура» — сам чернильный контур.

### Аксессуары
Один, и только один: **лента «Нить», привязанная к зеркалу**, развевающаяся назад по ходу движения. Это единственный аксессуар персонажа — он же физически связывает Веспу с отдельным UI-мотивом ленты. Новые аксессуары (шлем, чемодан, солнцезащитные очки и т.п.) не добавляются без пересмотра этого документа.

### Уникальная отличительная деталь
Лента у зеркала — единственный элемент, который отличает эту Веспу от «просто иконки скутера». Она обязана присутствовать в любой позе персонажа.

## 4. Неприкосновенные признаки

Обязано оставаться одинаковым во всех позах и генерациях:

- Пропорции корпуса (1.6:1) и диаметр/расположение колёс.
- Количество колёс — **два**, количество фар — **одна**, количество зеркал — **два**.
- Отсутствие рта.
- Форма и положение фары (единственный «взгляд»).
- Лента у зеркала — обязательный элемент, всегда одна.
- Палитра: только цвета из таблицы раздела 3, никаких новых оттенков.
- Толщина и цвет контура (`--color-ink`, 3–4px в 1024px).
- Отсутствие градиентов, теней-растяжек, глянца.
- Ракурс ¾ как базовый (если не указано иное для конкретной позы).
- Общий характер: сдержанность, отсутствие «мультяшной» утрированной мимики.

## 5. Запрещённые изменения

- Новые аксессуары (шлем, очки, багаж, флаг, значки) без пересмотра библии.
- Рот, брови или дополнительные «глаза».
- Изменение количества колёс, зеркал или самой ленты.
- Другие пропорции («бобблхед», удлинённый корпус, детская коренастость).
- Градиенты, объёмный рендер, фотореализм, хром.
- Случайный текст, надписи, номерные знаки, логотипы сторонних брендов на корпусе.
- Чрезмерно «детская» мимика (огромные слёзы-блики, звёздочки, взрывы восторга).
- Несогласованные оттенки красного/кремового вне палитры раздела 3.
- Использование персонажа в блоках с юридически значимыми обещаниями (суммы, гарантии сроков визы/стипендии).

## 6. Production prompt

Промпт даётся на английском — так стабильнее работают большинство image-gen моделей; описание вокруг него на русском.

### Base prompt (неизменяемый, используется в каждой генерации)

```
Flat 2D vector-style illustration of a stylized Vespa scooter character,
¾ front-left view, single round headlight as the only facial feature (no
mouth, no extra eyes), thin curved "eyelid" line over the headlight for
subtle expression, two wheels (front slightly smaller, offset forward),
simple handlebar with two round mirrors, one thin ribbon tied to the left
mirror flowing backward. Rounded geometric body, wide "wasp-waist" between
front shield and rear fender, proportions approx. 1.6:1 width:height. Bold
uniform ink outline (#211a14), rounded line joins, flat solid fills only —
no gradients, no gloss, no drop shadow baked into the image. Color palette
strictly limited to: body #b4262b, body shadow panel #8f1d21, outline
#211a14, headlight and ribbon #fffdf8, ribbon tip accent #b25000.
Background: transparent. Clean silhouette readable as flat black shape.
No text, no logos, no license plates, no additional characters, no
scenery, no cast shadow on ground.
```

### Negative prompt (постоянный)

```
mouth, smile, teeth, extra eyes, eyebrows, gradient, glossy, metallic
reflection, chrome, photorealistic, 3d render, drop shadow, cast shadow,
background scenery, text, watermark, logo, license plate, extra limbs,
extra wheels, helmet, sunglasses, luggage, flag, multiple characters,
motion blur, speed lines unless specified, low detail sketch, rough
linework, asymmetric mirrors, missing ribbon
```

### Отдельный prompt для мотива «Нить» (без персонажа)

```
Flat 2D vector ribbon/thread shape, single continuous curved band with
rounded ends, no character, no face. Bold ink outline (#211a14), fill
#fffdf8, one end accented with #b25000. No gradients, no shadow, no
background, no text. Clean silhouette suitable as a reusable UI motif
(progress bar fill, route line, breadcrumb).
```

### Правила использования reference image

1. Мастер-референс (утверждённое изображение ¾) прикладывается к **каждой** последующей генерации позы — не полагаться только на текстовое описание base prompt.
2. Если инструмент генерации поддерживает image-to-image/reference-conditioning — использовать его с весом, достаточным для сохранения силуэта, но не настолько высоким, чтобы блокировать нужное изменение позы.
3. Если reference image не поддерживается — генерировать 3–4 варианта на каждую позу и выбирать по чек-листу ниже, не первый попавшийся результат.
4. Никогда не описывать персонажа заново «с нуля» другими словами — всегда брать неизменяемый base prompt из этого документа и только добавлять к нему блок позы.

### Checklist визуальной проверки (для каждой сгенерированной позы)

- [ ] Два колеса, одна фара, два зеркала — ничего лишнего и ничего не пропало.
- [ ] Рта нет.
- [ ] Лента у зеркала присутствует и не заменена другим аксессуаром.
- [ ] Пропорции корпуса примерно 1.6:1, «талия» между щитком и крылом видна.
- [ ] Только цвета из таблицы раздела 3 — ни одного нового HEX.
- [ ] Контур сплошной, ink, без разрывов, без градиента.
- [ ] Фон прозрачный, нет наземной тени, нет декоративной сцены.
- [ ] Силуэт при заливке 100% ink остаётся узнаваемым как мотороллер.
- [ ] Эмоция читается по наклону века/корпуса/руля, а не по added-мимике.
- [ ] Нет текста, водяных знаков, номерных знаков, посторонних логотипов.

Если хотя бы один пункт не выполнен — генерация отклоняется и повторяется, изображение с visual drift не принимается в набор ассетов.

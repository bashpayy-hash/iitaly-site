# iItaly portal: Higgsfield exports

The portal shares `--font-sans` (Onest) and `--font-editorial` (Charter, Georgia, serif) with Modulo 1. Its header is the same MarketingHeader, with the three public navigation links and the portal actions. No portal-specific font download remains.

## Connect exports

Place reviewed exports in `public/media/higgsfield/`. Edit `src/data/higgsfieldVisuals.ts` with their real paths. Do not add paths until the corresponding files exist. Current poster paths are existing iItaly artwork, not newly generated Higgsfield outputs.

```ts
docs: {
  poster: "/media/higgsfield/docs.webp",
  video: "/media/higgsfield/docs.mp4",
},
```

The six stage keys are `start`, `docs`, `apply`, `dsu`, `visa`, `arrival`; legacy `documents` maps to `docs`. `HIGGSFIELD_TASK_VISUALS.translate` can override a stage for a particular task. Use a still WebP/PNG poster for every video. `HiggsfieldVisual` displays the poster when reduced motion is requested, video loading fails or autoplay is blocked; it pauses when offscreen / in a background tab and provides a pause control. No Higgsfield API key is used in the browser.

For the mascot, set `HIGGSFIELD_VESPI.celebrate` to the reviewed video path. Both the route mascot and the chat avatar use this setting. Celebration runs after `iitaly:task-saved`, after a successful save, rather than immediately on an attempted click. The route mascot stays hidden when the right chat is open. Existing approved stills remain available as a fallback; check animation and optional chime do not depend on a generated video.

The six prompts below produce six stage loops; the independent mascot reaction is a seventh export. Attach zhol slide 01 as the style reference for the stage videos. Use one approved frame as a composition reference across all six. Export square 1:1, 6 seconds, 24 fps, muted, with matching first and last frames; also export the first frame as WebP. Keep every essential object within the central 75% so a narrow slot never crops it. Documents are decorative, with no legible personal data or reproduced official seals.

# IItaly — бренд-бриф маскота (этап 1: аудит)

Источник: аудит `README.md`, `src/app/globals.css`, `src/app/layout.tsx`, `Header.tsx`/`Footer.tsx`, `Hero.tsx`, `HowItWorks.tsx`, `DocCheck.tsx`, `UniversitiesExplorer.tsx`, `PortalLogin.tsx`, `Logo.tsx`, `italy.ts` (`CITY_ICONS`). Зафиксировано после утверждения концепции «Веспа и Нить» — см. `docs/mascot-bible.md`.

## Главное обещание продукта

«Поступление сложное, но теперь я понимаю следующий шаг и ничего не потеряю» — сайт продаёт не мечту об Италии, а систему, которая ведёт по процессу. Прямая цитата позиционирования из брифа клиента: «система вместо агентства».

## Эмоциональное напряжение пользователя

Не «я не знаю Италию», а «я боюсь упустить шаг в бюрократии и потерять деньги/время». Вторичная аудитория (родители) добавляет: «я плачу за это и должен понимать, что получаю, без сюрпризов».

## Визуальные признаки бренда (уже в коде, не выдуманы)

- Кремовый фон (`--color-cream` `#faf5ec`), карточки на `--color-paper` (`#fffdf8`).
- Чернильные обводки и текст (`--color-ink` `#211a14`), плоские заливки, никаких градиентов.
- Жёсткие офсетные тени как CSS-переменные (`--shadow-sm/md/lg/xl`, `--shadow-red`, `--shadow-green`) — не запечены в растр, применяются к любому блоку.
- Капслок в заголовках, `Unbounded` для display, `Golos Text` для текста.
- Существующий микро-иконный язык на карте университетов (`CITY_ICONS` в `src/data/italy.ts`) — плоские силуэты ~22×22, `currentColor`, средняя толщина обводки.
- Тёмной темы нет (`color-scheme: light` без `prefers-color-scheme`) — все ассеты проектируются только под светлый фон.
- Текущий логотип (`Logo.tsx`) — абстрактная колоннада/портик, без персонажа; палитра `#b4262b` / `#fffdf8` / `#211a14`.

## Tone of voice (подтверждено текстами интерфейса)

Короткие фактические фразы, без придыхания и без паники даже в предупреждениях: «Есть замечания» (не «Ошибка!!!»), «От вопроса до посадки в самолёт», «Составить план бесплатно». Общесайтовый дисклеймер в футере уже честно ограничивает обещания: «Ответы ИИ могут содержать ошибки — критичное проверяет эксперт». Маскот обязан говорить в этом же регистре, не привносить новый тон.

## Роль маскота

Навигатор по системе, а не гид по Италии и не эксперт-всезнайка. Показывает следующий шаг, отмечает пройденное, предупреждает о сроках — без обещаний исхода (поступление/виза/стипендия).

## Лучшие места применения

1. Hero главной страницы — открывающая эмоция «маршрут понятен».
2. Онбординг / визард «Мой план» — сопровождение по шагам без давления.
3. Кабинет — прогресс, следующий шаг, empty state «пока пусто».
4. Проверка документов (`DocCheck`) — состояния «проверяю», «есть замечания», «всё в порядке».
5. Карта университетов — точечно, не перекрывая существующие пины и микро-иконки городов.
6. 404 и пустые состояния сайта.

## Ограничения по размеру и композиции

- Минимальный размер — 32–48px (навигация, аватар чата) — силуэт обязан читаться и там.
- Не может визуально спорить с уже существующими пинами и городскими иконками на карте (тот же порядок толщины линии, не крупнее активного пина).
- Hero-версия не должна ухудшать LCP — для главного экрана нужен лёгкий SVG/WebP, не тяжёлый PNG с эффектами.

## Что вызовет доверие родителей

Сдержанность и предсказуемость: отсутствие чрезмерной мимики, отсутствие драматизации в предупреждениях, ясная нейтральная поза по умолчанию, отсутствие вымышленных обещаний в репликах.

## Что будет привлекательно для подростков 16–18

Актуальная эстетика (не «детский» стиль), узнаваемый культурный референс (итальянский промдизайн, а не открыточный штамп), лёгкая ирония в мелких деталях без потери компетентности.

## Что нельзя визуально перебивать

- Существующие пины и микро-иконки городов на карте университетов.
- Жёсткие офсетные тени карточек — маскот не должен требовать собственной сложной тени поверх системной.
- Крупные капслочные заголовки `Unbounded` — маскот не конкурирует с ними за внимание на одном экране, размещается сбоку/под текстом.

## Утверждённая концепция

«Веспа и Нить» — персонаж (стилизованный мотороллер Vespa, попутчик) + отдельный переиспользуемый мотив (лента-след, используется в местах без места для полного персонажа: прогресс-бары, маршрутная линия на карте, breadcrumbs). Полная спецификация — `docs/mascot-bible.md`.

# Реальные роли Веспи в продукте

18 октября 2026. Пользователь попросил внедрить изменения через GitHub и
Higgsfield, а не оставлять новые позы в виде промптов и пустых записей реестра.

Два изображения созданы в Higgsfield по утверждённому референсу Веспи:

- **Копилот:** крупный портрет без скутера, кремовый воротник с оливковой
  отделкой. Используется в квизе, шагах, онбординге и чате.
- **Эксперт:** очки, нейтральный документ и открытый жест в сторону текста.
  Полная фигура — в советах справочника и предложении проверки; портретный
  кроп — у загрузки и сохранённого разбора в кабинете.

Лицо, красный шлем, кремовая полоса-маршрут и оливковая точка сохранены.
На документе нет печати, знака одобрения или выдуманного результата.
Скутер на дороге явно использует `route + figure`. Роль `celebrate` остаётся
с прежним изображением: новый рисунок для неё не выдаётся за готовый.

## Поставка

`design/mascot/vespi/roles/` содержит два lossless-мастера, точные промпты,
job ID, хеш исходного PNG и координаты портретного кропа. Технические производные
созданы кадрированием / уменьшением; лицо не перерисовывается при упаковке.

Все шесть production WebP вместе — **57 524 байта**. Посетитель получает
нужный responsive-вариант с того же домена; мастера и сервис генерации в
браузер не попадают. Прозрачность проверена на светлом фоне, портреты —
в размерах 96 и 48 px. Новые URL версионированы, старые файлы не перезаписаны.

Палитра, шрифты, фоны, источники, цены, API, авторизация, оплата и значения
статусов документов не менялись. Новые карточки или CTA не добавлены.

## Проверка

Общий browser-review дополнен проверкой фактически декодированного `currentSrc`,
всех кандидатов `srcSet`, отсутствия fallback у новых ролей и полного райдера
на дороге. Проверяется побайтное совпадение файлов public и static export,
наличие всех шести изображений и суммарный бюджет ≤ 64 KiB. Прежние проверки
палитры, одного видимого персонажа, доступности, сохранения анкеты и запрета
действий на будущем шаге сохранены.

Скриншоты «до» сняты с cddf982, «после» — с этой ветки. Профиль кабинета и
API-ответы синтетические; проверки не используют реальные данные пользователя.

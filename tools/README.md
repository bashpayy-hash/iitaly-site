# tools/

Внутренние инструменты владельца. **Этот каталог не попадает в сборку** —
Next.js публикует только `public/`, а `tools/` лежит рядом с ним и остаётся
в репозитории.

## admin.html — выдача доступа в кабинет

Раньше файл лежал в `public/` и вместе со сборкой уезжал на
`https://iitaly.kz/admin.html`, где его мог открыть кто угодно и где его
индексировали поисковики. Секрета в файле нет — `STATS_KEY` вводится руками
и сервер без него отказывает, — но публично доступная панель управления
клиентами это приглашение её поковырять, а сам ключ панель держит в
`localStorage` браузера.

Открывать локально:

```bash
npx serve tools -l 4322      # затем http://localhost:4322/admin.html
```

или просто двойным щелчком по файлу. Оба способа работают: бэкенд
разрешает источник `null` (файл с диска) и `localhost`, пока список
`ALLOWED_ORIGINS` на сервере не задан. Если список уже прописан — добавь
в него `http://localhost:4322`, иначе браузер не пропустит запрос.

Ключ `STATS_KEY` берётся из Railway → Variables проекта бэкенда.

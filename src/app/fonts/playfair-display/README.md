# Playfair Display

Source: https://github.com/google/fonts/tree/main/ofl/playfairdisplay

The upright and italic variable fonts are distributed under the SIL Open Font License in OFL.txt. Downloaded 2026-10-19 and losslessly compressed from TTF to WOFF2 with fontTools; all glyphs and variation axes are retained. Loaded through next/font/local so the editorial font does not require a Google Fonts build-time request.

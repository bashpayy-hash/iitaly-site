# iItaly — галерея на бумаге

Полная замена прежней дизайн-системы по четырём файлам владельца.

- Канонические токены: `design/tokens.json`, `src/styles/variables.css`, `src/styles/theme.css`.
- Восемь нейтральных цветов, Playfair Display с кириллицей и Inter, плоские поверхности без градиентов и теней.
- Главная: интерактивный пример маршрута, монументальный знак, три этапа, живопись и один блок цены.
- Гайды: четыре отправные ситуации, 13 последовательных тем, прежние прямые ссылки и официальные источники.
- Кабинет: одна навигация, открытые инструкции/файлы/сроки; минимальный помощник сохраняет контекст шага.
- Удалены повторяющиеся 3D-персонажи, акварели и разделение задач по ролям. Старые серверные подписи нормализуются при чтении; идентификаторы, включая `familyDocs`, сохраняются для совместимости.
- Репродукции Каналетто — из открытой коллекции The Met; происхождение указано в `public/art/sources.json`.

## Проверка

`npm run check:palette`, `npm run lint`, `npm run build`.

GitHub Actions проверяет все маршруты на двух размерах экрана, клавиатуру, пошаговые гайды, контекст чата, анкету, карту, сравнение, сохранение документов, ошибки оплаты, облачный кабинет и геометрию бланка permesso. Все обращения к оплате, ИИ и защищённому API в браузерных тестах перехватываются синтетическими обработчиками.

Скрипт `scripts/design-guard.mjs BASE_SHA` защищает цены, факты каталога, правила поступления, платёжные/API-контракты, зависимости и координаты официального бланка. Старые проверки внешнего вида заменены проверками новой системы; история прежних решений сохранена в Git.
